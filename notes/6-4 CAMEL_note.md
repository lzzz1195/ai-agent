# 6-4 CAMEL框架项目学习心得

# 当前学习的CAMEL框架比较浅显，主要是通过两个智能体通过角色扮演形式的有限次对话来逐渐完成任务。

# 设计者要给出引导性提示来规定任务，告知智能体的角色，设定行为约束和沟通协议。

# 目前大概实现了一下书中提到的将两个智能体分别饰演心理学家和作家来共同完成撰写一本心理学科电子书的任务，相关对话内容已经存放在了6-4 log.txt文件中。

# 我设定了30轮的对话限制，前8轮便完成了初步编写，在第9轮转而进行精修，校对。最后在13轮作家角色发出了 <CAMEL_TASK_DONE>字段完成了任务。中止了全过程。总共消耗了309,514 token。

# CAMEL框架比较好上手进行初步验证，想验证想法又不想搭复杂系统的时候可以使用。但局限性在于对于提示设计过于依赖，且调试难度大，需要阅读聊天记录来具体区分是提示词的问题还是角色界定问题。

# 当然对于复杂系统来说，还是LangGraph、AgentScope成熟一点。
