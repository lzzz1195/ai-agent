# 6-2 AutoGen 项目学习心得

## 这里面创建了一个AutoGen框架的项目，分了四个角色（需求经理、工程师、代码审计和用户代理）用于创建一个streamlit项目查询比特币价格

## 我使用的deepseek api 里面的用户代理写成了接受用户输入的形式

## 代码运行了四个循环，主要问题集中于访问查询api的时候超时报错，代码审计那里测试过不去，工程师反复修改。

## 每次都把大量的对话作为历史保存，再进入下一个循环，这一来一回请求了12次 dp api，消耗了392,175的token（1.54 CNY）

## 这个框架让大模型分别饰演自己的角色，像开会一样一步一步解决问题，各司其职。在设计的时候需要把边界明确，不要干职责外的事情。不然会乱套

## 同时要明确循环次数和中止条件，不然消耗token没完没了还解决不了问题。
